# CrowdChange Notifications

CrowdChange is equipped with a host of informative email notifications for each type of user role.

Here is an in-depth overview of existing notifications, their triggers, and which user roles are required to receive them.  

|                     **Notification Name**                     |                                                                                  **Trigger**                                                                                   |                      **Sent To**                       |
|---------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------|
| *****Related to basic fundraiser actions*****                                                                                                                                                                                                                                                         |||
| Fundraiser created (Welcome / Confirmation)                   | Fundraiser created                                                                                                                                                             | * Fundraiser owner                                     |
| New fundraiser created (Admin Notification)                   | Fundraiser created (maybe with pending approval status)                                                                                                                        | * Site Admins                                          |
| Fundraiser Owner Invite                                       | Fundraiser created                                                                                                                                                             | * Fundraiser owner                                     |
| Fundraiser Approved                                           | Fundraiser approved by Admin                                                                                                                                                   | * Fundraiser owner                                     |
| Fundraiser Rejected                                           | Fundraiser rejected (not approved) by Admin                                                                                                                                    | * Fundraiser owner                                     |
| Fundraiser Updated (Admin Notification)                       | Fundraiser updated by an owner                                                                                                                                                 | * Site Admins                                          |
| New Personal Page Created (Admin Notification)                | Personal fundraising page created by a user                                                                                                                                    | * Site Admins                                          |
| Personal Page Created (Team Captain Notification)             | Personal fundraising page created by a user within a team                                                                                                                      | * Team Captain / Owner                                 |
| New Personal Page Created                                     | Personal fundraising page created by a user                                                                                                                                    | * Fundraiser owner * Personal page owner               |
| Personal Page Registered                                      | Personal fundraising page created by a user and registration paid (if "My event requires registration" option is selected in Fundraiser settings)                              | * Fundraiser owner * Personal page owner               |
| Personal Page Deleted                                         | Personal fundraising page deleted by a user                                                                                                                                    | * Site Admins                                          |
| Personal Page Restored                                        | Personal fundraising page restored by an admin                                                                                                                                 | * Personal page owner                                  |
| User Invite                                                   | Personal page created by an Admin or fundraiser owner                                                                                                                          | * General user (maybe even not registered)             |
| New Team Created (Admin Notification)                         | Team page created for fundraiser                                                                                                                                               | * Site Admins                                          |
| New Team Created                                              | Team page created for fundraiser                                                                                                                                               | * Fundraiser owner                                     |
| Team Deleted                                                  | Team fundraising page deleted by a user                                                                                                                                        | * Site Admins                                          |
| Team Restored                                                 | Team fundraising page restored by an admin                                                                                                                                     | * Team page owner / Team captain                       |
| Team Captain Invite                                           | Team page created for fundraiser                                                                                                                                               | * Team Captain / Owner                                 |
| Fundraiser Auto-Closed (Admin Notification)                   | Fundraiser closed automatically at a certain date / time (as set with the "Stop accepting funds on date" option).                                                              | * Site Admins                                          |
| Fundraiser Auto-Opened (Admin Notification)                   | Fundraiser opened automatically at a certain date / time (as set with the "Start accepting funds on date" option).                                                             | * Site Admins                                          |
| Fundraiser Managed Page Created                               | Personal page created through managed pages                                                                                                                                    | * Personal Page owner                                  |
| Fundraiser User Invite                                        | User invited to manage fundraiser                                                                                                                                              | * Invited user                                         |
| Fundraiser - Zero Raised                                      | Sent when fundraiser is created but hasn't raised any money in \[x\] (5/10/15) days. Only sent to Campus and HQ site types.                                                    | * Fundraiser owner                                     |
| Upcoming Event                                                | Sent \[x\] (4/7) days before the event. There are 2 different templates - one for events that sell tickets, and one for regular events. Only sent to Campus and HQ site types. | * Fundraiser owner                                     |
| Fundraiser Support Message (Admin Notification)               | User has a technical or refund request and clicks the Contact Us button (without addressing to the host).                                                                      | * Site Admins                                          |
| Fundraiser Support Message                                    | User has a fundraiser-related question and clicks the Contact Us button (with question for the host option).                                                                   | * Fundraiser owner                                     |
| Milestone Notification                                        | Automatically sent out on set triggers.                                                                                                                                        | * Depends on trigger                                   |
| *****Related to additional fundraiser options*****                                                                                                                                                                                                                                                    |||
| Test Mode Enabled (Admin Notification)                        | Test mode enabled for a fundraiser (fundraiser not shown to general public)                                                                                                    | * Site Admins                                          |
| Test Mode Disabled (Admin Notification)                       | Test mode disabled for a fundraiser                                                                                                                                            | * Site Admins                                          |

| Fundraiser Closed (Admin Notification)                        | Fundraiser closed by an owner (stop collecting donations)                                                                                                                      | * Site Admins                                          |
| Fundraiser Re-opened (Admin Notification)                     | Fundraiser re-opened by an owner (start collecting donations again)                                                                                                            | * Site Admins                                          |
| Fundraiser Deleted (Admin Notification)                       | Fundraiser deleted by an owner                                                                                                                                                 | * Site Admins                                          |
| Event stopped ticket sale (Admin Notification)                | Ticket sale stopped for an event by fundraiser owner (donations still collected, but tickets not available)                                                                    | * Site Admins                                          |
| Event re-opened ticket sale (Admin Notification)              | Ticket sale re-opened for an event by fundraiser owner                                                                                                                         | * Site Admins                                          |
| eCard Copy                                                    | At the same time when original eCard is sent to recipient                                                                                                                      | * Donor (if send me a copy is selected)                |

| Tribute Copy                                                  | At the same time as original tribute is sent to recipient (when completing a donation if purchasing cards were required)                                                       | * Donor                                                |
| Tribute                                                       | When completing a donation if purchasing cards were required                                                                                                                   | * Personal page's owner                                |
| Subscription Auto-Cancelled                                   | Recurring donations were cancelled as campaign stopped                                                                                                                         | * Fundraiser owner * Donor                             |
| Subscription Cancelled (Admin Notification)                   | Recurring donations were cancelled                                                                                                                                             | * Site Admins                                          |
| Subscription Cancelled                                        | Recurring donations were cancelled                                                                                                                                             | * Fundraiser owner * Donor (as confirmation)           |
| Subscription - Card Expiring Soon (Admin Notification)        | Card linked to recurring donations will be expired soon (in \* days)                                                                                                           | * Site Admins                                          |
| Subscription - Card Expiring Soon                             | Card linked to recurring donations will be expired soon (in \* days)                                                                                                           | * Donor                                                |
| Subscription - Card Was Updated                               | Card linked to recurring donations was updated (expiry date or CVS/CVV changed)                                                                                                | * Donor (as confirmation)                              |
| Subscription Changed (Admin Notification)                     | Recurring donation date was changed                                                                                                                                            | * Site Admins                                          |
| Subscription Changed                                          | Recurring donation date was changed                                                                                                                                            | * Donor (as confirmation)                              |
| Subscription - Recurring Donation Failed (Admin Notification) | Transaction could not be processed (3 more tries then it will be cancelled)                                                                                                    | * Site Admins                                          |
| Subscription - Recurring Donation Failed                      | Transaction could not be processed (3 more tries then it will be cancelled)                                                                                                    | * Donor                                                |
| Subscription Charge Error - Cancelled (Admin Notification)    | Transaction cancelled after 3 additional tries to process                                                                                                                      | * Site Admins                                          |
| Subscription Charge Error - Cancelled                         | Transaction cancelled after 3 additional tries to process                                                                                                                      | * Donor                                                |

| ReportFundraisers                                             | Admin → Report → Fundraisers Report → Excel                                                                                                                                    | * Whoever requested it                                 |
