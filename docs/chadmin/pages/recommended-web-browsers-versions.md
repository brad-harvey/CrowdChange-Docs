# Recommended Web Browsers & Versions

CrowdChange is compatible with all modern web browsers. To ensure you get the best experience possible, we recommend using the most up-to-date version of one of the following:  

| **Browser** |         **Recommended Versions**          |
|-------------|-------------------------------------------|
| Chrome      | Latest                                    |
| Firefox     | Latest and extended support release (ESR) |
| Edge        | 2 most recent major versions              |
| Safari      | 2 most recent major versions              |
| iOS         | 2 most recent major versions              |
| Android     | 2 most recent major versions              |

Being a cloud platform, our software does not run natively on user devices. It is simply accessed via a web browser. Therefore we do not have specific Operating System requirements.
