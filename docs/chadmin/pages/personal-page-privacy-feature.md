# Personal Page Privacy Feature

When enabled, the Personal Page Privacy feature makes all personal pages across your CrowdChange site private. This means that they can not be seen or accessed by the general public - only via a direct link to the page. When users create Personal Pages, they receive an email which contains the direct link to their page. They can then share this unique link to anyone they would like to have access to donate to their page.  
This feature is **NOT**enabled by default and can only be enabled by a CrowdChange Admin.

## This feature also means the following (by default):

* Donors cannot search for personal pages or view the list.

* Donors cannot donate through a participant without a direct link to their personal page.

* Donors cannot see personal pages within teams.

* Personal Page owners are unable to see other personal pages while logged in.

* Team owners can only see transactions made to the team, not to team members.

* Fundraiser Hosts can only see that a donation was made to the fundraiser or to a team. If a donation was made through a personal page, the host is unable to see which page the donation came through.

If you'd still like to allow donors to search for personal pages and view the list, simply enable the '**Allow to search for personal pages** ' toggle in **Admin → General Settings**.  
Site Admins can access private personal pages (without a direct link) via **Admin \> Reports \> Personal Pages Report**.
