# Fundraiser link displays 'Page not Found' Error message

If you have shared or visited a CrowdChange link and are seeing a '*Page not Found*' screen (otherwise known as "Error 404"), below are some possible reasons why:

* [**Banking**](stripe-banking-overview.md)information on the fundraiser has not been set up/verified by the payment processor (Stripe).

* The fundraiser is pending [**Approval**](fundraiser-approval-admins.md) from site admins.

* Incorrect URL: This is caused by mistyping or misspelling a URL.

* The page you are trying to view has been deleted and doesn't exist anymore.
